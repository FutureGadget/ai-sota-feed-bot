Dynamic Workflows

TL;DR

Anthropic introduced Dynamic Workflows (“ultracode”) for Claude Code, first surfaced in late May alongside the Opus 4.8 release and detailed over the following days. The capability coordinates large numbers of agents within a single workflow to take on complex engineering tasks, with Anthropic's own “A Harness For Every Task” post laying out the model.

What's new: Anthropic's own writeup, “A Harness For Every Task,” closes the loop on the launch coverage — framing Dynamic Workflows as a general orchestration harness rather than a one-off feature.

💡 Dynamic Workflows is the orchestration primitive for fanning out many agents deterministically from a single Claude Code run — directly relevant if you're moving past single-agent prompting toward parallel, structured agent pipelines.
