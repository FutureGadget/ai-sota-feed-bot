Latest change

Nov 23: ToolSmith has multimodal search agents generate and reuse their own tools across 13 benchmarks, three days after Search-RSI reported 9.8- and 9.5-point gains at 9B and 27B by growing the agent's search world.

Builder action

Before letting an agent add tools or memory at runtime, gate it: review generated tools before they enter the shared registry, log which ones get reused, and measure any cached-memory scheme's answer quality on your own long-context traffic, not only its prefill latency.

Earlier contextThe story so far

This thread is a reading list of LLM research papers grouped by shared wording, not one event. From Nov 4 it ran through agent benchmarks, kernel and serving work, eval validity and multimodal hallucination, then Nov 13-19 papers on abstention, jailbreak screening and lie probes.
