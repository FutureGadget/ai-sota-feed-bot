How this is ranked
  • Discovery is a union of GitHub repo searches (new-and-fast repos, topic-tagged repos, and name-family ports), never a single query.
  • One skill is counted once even when a repo vendors it for many harnesses; the copy count is portability, not popularity.
  • Stars are shown but never ranked. Adoption is fork ratio, because installing a skill means copying it.
  • Ranking families lets a ported setup be measured as one concept instead of many small repos.
  • A capability group is shown only when at least two skills in the setup name that capability, and the most focused setup wins the group: two matches out of five skills beats four out of four hundred.
  • Core means the capability serves agent and platform engineering; adjacent means useful but broader. Off-lens setups are not listed at all.
  • 419 setups were excluded for being outside the platform/agent-engineering lens.
