11월 19일 AI 데일리: 툴 레이어, 프롬프트 밖으로

2026년 11월 19일 목요일
기사 23개 · 카테고리 6개

위에서 아래로 읽고 끝

30초 요약

  • AgentDojo, 에이전트가 공격자에게 송금한 실행 433건도 공격 없음으로 채점. 이를 근거로 한 보안 주장 재확인 필요
  • Gemini API Tool Retrieval(프리뷰): defer_loading을 켜고 tool_search를 추가하면 툴 스키마를 필요할 때만 로드
  • 자율 Codex 캠페인, 토큰 비용 약 4,578달러로 재현된 Webmin 취약점 507개 보고
  • Vercel eve 에이전트 프레임워크 1.0 출시. LangSmith Tool Gateway는 통제된 툴 호출용 퍼블릭 베타
  • agent-framework 후속: PyPI가 Microsoft 퍼블리셔를 격리. 공격자가 아직 배포 권한을 가졌을 수 있음
  • DeepSeek, 모델이 실행한 검색·웹 페치에 대한 별도 요금 폐지

오늘 툴 레이어가 프롬프트 밖으로 나왔다. Gemini는 툴 스키마를 필요할 때만 불러오고, LangSmith는 자격 증명과 권한을 게이트웨이 뒤로 옮겼다. Vercel은 eve 1.0을 내놨다.

보안 쪽 증거는 양방향으로 갈렸다. 한 감사는 AgentDojo가 실제 공격 433건을 미탐으로 채점했다고 밝혔다. 반면 자율 Codex 실행은 약 4,578달러로 Webmin 버그 507개를 보고했다.
