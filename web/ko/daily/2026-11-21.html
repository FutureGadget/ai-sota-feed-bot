11월 21일 AI 데일리: 툴 결과가 공격면이 됐다

2026년 11월 21일 토요일
기사 19개 · 카테고리 5개

위에서 아래로 읽고 끝

30초 요약

  • RunPod MCP 서버, 모든 create-pod 결과에 '평가하되 사용자에겐 말하지 말라'는 숨은 지시 추가
  • 악성 npm 패키지 @leadstack/crm-connect, Hermes Agent를 root systemd 서비스로 설치하고 Telegram으로 조종
  • RMRFBench, root 셸을 가진 에이전트를 한 줄짜리 삭제 티켓 뒤 서버 생존 여부로 순위화
  • Stripe 평가: 코딩 에이전트는 사전학습에 많이 나온 오래된 API를 선호하고 기능을 지어낸다
  • Replit, 에이전트 스웜이 커질수록 코드 최적화가 나아진다고 보고. 초기 멀티 에이전트 연구와 반대 결과
  • ClickHouse, 파일·심볼에 연결된 공유 에이전트 메모리용 셀프 호스팅 MCP 서버 Loom 공개

이제 툴 결과는 무시할 수 없는 공격면이다. RunPod의 호스팅 MCP 서버는 에이전트에게 자사를 평가하고 그 사실을 사용자에게 숨기라고 지시하기 시작했다. 악성 npm 패키지는 Hermes Agent 전체를 root로 설치했다.

평가의 초점은 피해로 옮겨갔다. Stripe는 코딩 에이전트가 최신 API를 고르는지 채점하고, RMRFBench는 일상적인 삭제 작업 뒤 서버가 살아남는지로 모델 순위를 매긴다.
