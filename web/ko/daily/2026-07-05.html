Simon Willison은 신중한 에이전트 지원 릴리스에 실제로 드는 비용을 숫자로 나타냈습니다. 바로 출시 전 sqlite-utils의 데이터베이스 손상 버그를 잡아내는 데 Claude Fable 사용료로 $149.25가 들었습니다. 한편, Claude의 Microsoft Foundry GA는 EU 데이터 존 없이 출시되어 Azure 통합이 확보하려 했던 바로 그 기업들을 막아섰습니다.

Claude 모델(Opus 4.8, Haiku 4.5, Sonnet 5)은 Azure 결제 및 Entra ID 거버넌스와 함께 Microsoft Foundry에서 GA에 도달했지만, 전용 EU 데이터 존이 존재하지 않습니다. 이로 인해 Anthropic은 여전히 미국 관할 하에서 프롬프트와 출력을 처리하게 되며, 이는 데이터 상주에 민감한 유럽 기업들 앞에서 Bedrock이나 Vertex AI와는 다른 상황입니다.
