30초 요약

  • Dragos 카나리 테스트: 프롬프트 약 200만 개에서 AI 제공업체 침해 세 건과 무시된 Zero Data Retention 설정 확인
  • CVE-2026-28400: 기본 권한 컨테이너가 Docker Model Runner를 통해 Docker Desktop VM 디스크를 손상시킬 수 있었다
  • incus-spawn과 Sandscale은 코딩 에이전트에게 사용자 자격 증명 대신 전용 Linux 머신이나 Firecracker microVM을 준다
  • Enola는 에이전트 메모리를 코드 심볼에 묶어, 이후 세션이 바뀐 코드에 맞춰 메모를 다시 검증하게 한다
  • Inkling 2 Mini는 토큰마다 12개 레이어를 세 번 반복 실행한다. vLLM이 출시 당일 서빙을 지원했다

AI 제공업체는 사용자가 보낸 데이터를 흘린다. Dragos는 카나리 프롬프트 약 200만 개를 심어 제공업체 침해 세 건을 잡아냈다. 프롬프트를 열람한 리셀러와 무시된 Zero Data Retention 설정도 확인했다.

빌더들은 엣지에서 대응했다. 새 도구들이 코딩 에이전트를 격리된 워크스테이션과 microVM에 올렸고, 로컬 스캐너는 실행 전에 에이전트 설정에서 살아 있는 키를 찾는다.
