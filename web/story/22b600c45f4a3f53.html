Show HN: Viberia – Civ/Polytopia-like command center for AI agents (BYOK/BYOS)

Hey HN, This is my take on the agent harness. Everything on an isometric map. Agents are grouped into "buildings" that run in a sequence or a loop; e.g., the CodeForge has an agent that writes a PRD, another one that implements, and a third that reviews. Everything is customizable, you build your own buildings/teams however you want. It's a Tauri app, really light (about 8x less energy than the closest competitor I benchmarked, so it actually runs from a coffee shop on battery). It's macOS only for now, but ping me if you are willing to test the Windows or Linux version. I've been dogfooding this for months and would love to get some feedback, feature requests, and bug reports so I know what to focus on next.
