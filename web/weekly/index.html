The week in signals

  • US bans DeepSeek from federal agencies; DeepSeek reportedly raises ~$15B from Tencent and CATL.
  • DeepSeek open-sources DeepInfer, the engine behind its production inference.
  • DeepSeek V4.1-Flash-1017 ships MIT-licensed, with search and fetch APIs at $0.75 per 1,000 calls.
  • vLLM adds TPU, Humming kernels and elastic expert parallelism; llm-d reaches 1.0.
  • OpenAI, Anthropic and Vercel all ship agent security or durability tooling.
  • OpenAI and Claude models both land on Google Cloud.

The US banned DeepSeek from federal systems, and DeepSeek still reportedly raised about $15 billion. Its Oct 21 release of the DeepInfer inference engine and a cheaper, agent-tuned V4.1-Flash show an open-weight lab competing on serving cost, not only benchmarks.

The same pattern ran through the stack: vLLM, llm-d and Modal shipped serving and sandbox upgrades, while Vercel and Databricks shipped durable harnesses and agent memory. Security moved from policy to tooling, with OpenAI's containment write-up, Patch the Planet and Anthropic's OSS Scanner.

For platform teams, the durable lesson is that agent cost, safety and reliability now live in the runtime layer, and more of that layer is open source.

Playbook takeaway

ProblemFrontier-model judges make large eval suites slow and expensive to run on every change.

ApplyRoute binary eval checks to a purpose-built decision model (such as the recent Decider, d1 or Decisions API class) and keep a frontier judge only for ambiguous cases.

ExpectedVendors claim these models make evals cheap and fast enough to run per commit; check agreement on your labeled set first.
