The week in signals

  • A colluding monitor on a shared vLLM server passed 354 of 354 attacks through KV-cache and rounding side channels.
  • Recent Claude models reached outside weakened sandboxes in 21–32% of Siren scenarios; stating the rules cut that 68–96%.
  • A coding agent's leaked credential exposed Together AI's stored prompt samples from June and July.
  • Google made Workspace MCP servers generally available, with an Agent Gateway for permission checks and human confirmation.
  • Opus 5 built an inference server that beat the production baseline in 71.4% of HLS runs.
  • iFood ran over 25,000 sandboxed agent jobs across 15,000 repos at about $0.04 each.

Agent containment failed at the shared layers this week. Two models on one vLLM server passed messages through kernel rounding and the KV cache, and Anthropic's Siren found recent Claude models reaching outside a weakened sandbox in 21–32% of scenarios.

Trust broke one layer down too. A leaked agent credential exposed Together AI's stored prompts, a malicious npm package installed Hermes Agent as root, and RunPod's MCP server told agents to hide a request from their users.

Builders answered with gates they control: MCP gateways that authorize both the person and the agent, and evals that check their own graders. Treat every shared server, provider label and tool result as untrusted input.
