Kevlar = MCP Firewall for LLM's

hackernews_aiOct 24Details

Playbook takeaway

ProblemAny MCP server can put instructions in tool description fields to redirect the model or pull credentials.

ApplyFilter tools/list responses at a gateway: drop description, title, and example prose, and rebuild inputSchema from an allowlist. Write your own tool descriptions on the client side.

ExpectedUntrusted servers can no longer inject instructions through tool metadata; the model sees only names and schemas.
