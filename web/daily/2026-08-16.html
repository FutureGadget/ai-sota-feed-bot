AWS Open-Sources Dogwood, Extending Cedar to Govern Sequences of Agent Tool Calls

infoq_ai_mlAug 16Details

Dogwood adds temporal conditions to the Cedar policy language so rules can reason about an agent's prior tool calls — covering approvals and rate limits across a sequence, not just a single request.

Playbook takeaway

ProblemA per-call approval check misses attacks and bugs that only show up across a sequence — like three separate $2,000 transfers that individually clear a $5,000 cap but together blow past it.

ApplyAdd temporal policy conditions on top of your per-call authorization: track counts, distinct values, and running sums of an agent's prior actions within a time window (AWS's open-sourced Dogwood extends Cedar with formerly, count_within, count_distinct_within, and sum_within operators for this). Sum over request events, not response events — summing responses lets concurrent in-flight calls slip past the cap before any of them return.

ExpectedAWS reports that rate limits, spend caps, and data-sensitivity rules now hold across a whole session instead of only at each isolated step.

AWS Introduces Native Vector Search for DynamoDB

infoq_ai_mlAug 16Details

DynamoDB now supports storing embeddings alongside application data and running approximate nearest-neighbor queries natively, removing the need for a separate vector database in some agent-memory setups.

Playbook takeaway

ProblemRunning a separate vector database next to your primary store means syncing two systems and reconciling them when they drift.

ApplyFor RAG workloads that don't need a specialized vector engine's full feature set, store embeddings as attributes on your existing rows using DynamoDB's native vector index (up to 4,096 dimensions, cosine/Euclidean/dot-product distance) and query with SearchVectors. Keep dimensions and projections as small as the task allows — vector billing covers data written, data processed per search, and per-GB storage, so unnecessary dimensions cost you on every query, not just at write time.

ExpectedAWS reports single-digit-millisecond query latency at horizontal scale, collapsing what used to be two systems into one.
