Coding agents: proving what the agent actually checked 5 items

Four new open-source tools gate agent output on evidence: pinned tool hashes, signed file digests, independently written checks, and specs tied to behaviour.

Show HN: Verfy – checks an AI coding agent's tool calls before they run

Hacker News AIDetails

Pins MCP tool definitions by SHA-256 and blocks a tool whose description changes after approval; it also reads scripts before Claude Code runs them.

Show HN: Slipmark – make AI agents prove what they checked

Hacker News AIDetails

Binds each agent sign-off to a SHA-256 of the files it read and fails CI when any of them change afterwards; no model calls.

Show HN: Apex verify – an independent model writes the checks your AI skipped

Hacker News AIDetails

A different model writes the checks the coding agent skipped, proves they can fail, and returns ready or not ready with evidence.

Agent_primitives – tie each app behaviour to the specs that prove it

Hacker News AIDetails

Keeps each required behaviour linked to the spec that proves it, so a new agent session can't quietly weaken a spec and stay green.
