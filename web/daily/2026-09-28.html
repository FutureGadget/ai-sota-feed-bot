Agent Security: Secrets and Visibility 2 items

Two releases target the same gap: keeping credentials and network activity outside the agent's own trust boundary.

Credentials API for Gemini Managed Agents

philschmidDetails

Gemini Managed Agents store secrets once by ID; an egress proxy injects them on the wire so they never enter the agent sandbox.

Playbook takeaway

ProblemA secret placed in the agent sandbox can be read, logged, or exfiltrated by a prompt-injected agent.

ApplyStore each credential once in a secrets service, give the agent only an ID reference, and have an egress proxy add the real value to outbound requests.

ExpectedGoogle claims the agent can call authenticated APIs without ever holding the raw secret, which shrinks what a compromised run can leak.
