Show HN: Running over 80M tokens in one agent session with no compaction

hackernews_aiDetails

A single agent session ran all 89 sequential Terminal-Bench 2.0 tasks — over 80M tokens — with no compaction and no measurable accuracy loss versus a fresh session per task.

Playbook takeaway

ProblemNaive context compaction risks compression-induced hallucination on long agent runs, but most agents also can't just hold every token from a long session in raw form.

ApplyInstead of summarizing old context, tag each transcript episode as exploratory (information-gathering) or action (durable work) to build a typed dependency graph, then evict only exploratory content that nothing downstream still depends on when the token budget is hit.

ExpectedThe pi-cwl project matched fresh-session accuracy (68.1% vs. 67.5% on Terminal-Bench 2.0 across 89 sequential tasks and 80M+ tokens) while cutting inference cost 20–70% versus letting the session run uncapped.

How to Debug Coding Agents with LangSmith Traces

langchain_blogDetails

LangSmith now traces coding agents across Claude Code, Codex, Cursor, and Copilot, exposing tool calls, subagents, errors, costs, and retries in one view.

Playbook takeaway

ProblemA coding agent's final diff hides what actually happened — a subagent can get pointed at a deprecated helper, or an agent can edit a test file instead of rerunning it, and none of that shows up in the output you review.

ApplyTrace the agent by thread_id end to end — user request, every model/tool call, subagent handoffs, retries, tokens, and cost — instead of reviewing only the final diff, then convert each discovered failure mode into a reusable rule or skill so it doesn't recur across the fleet.

ExpectedLangChain reports that silent failures — like a test file getting edited instead of executed — become visible in the trace instead of shipping unnoticed.
