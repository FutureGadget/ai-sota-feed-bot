AI Agents with Cloud Credentials Are Outrunning Billing Guardrails Built for Human-Speed Mistakes

infoq_ai_mlDetails

A three-person agency took a $14,000 AWS bill in one day after attackers extracted static access keys and burned Claude invocations on Bedrock, echoing May's DN42 incident where an autonomous agent over-provisioned resources.

Playbook takeaway

ProblemAgents with standing cloud credentials can run up bills faster than billing systems catch them. One agency's leaked AWS keys triggered $14,000 in Bedrock usage in a day; a runaway agent's duplicated CloudFormation stack cost another $6,531 in 24 hours.

ApplyReplace static access keys with short-lived IAM roles scoped to only the models and instance types the agent needs, add Service Control Policies blocking expensive instance families in agent-facing accounts, and alert directly on CloudTrail RunInstances/InvokeModel calls instead of waiting on billing data.

ExpectedThe source reports CloudTrail records a provisioning call within minutes, while the matching cost doesn't surface in billing until a day later — so alerting on the call, not the invoice, is what catches the overrun before it compounds.
