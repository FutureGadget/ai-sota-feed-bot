Un-Mused: How a Single Debug Setting Bypassed macOS Security in Meta's AI Client

infoq_ai_mlDetails

Researcher Patrick Wardle found an unpatched macOS zero-day where a single debug setting let unprivileged software abuse Muse's extensive assistant permissions.

Playbook takeaway

ProblemA single undocumented debug preference key in Meta's Muse desktop client let an unprivileged local process redirect the assistant's voice-dictation traffic and inherit its OS permissions, with no admin prompt required.

ApplyAudit every debug/diagnostic config key your agent client ships with in production for whether an unprivileged local process can write it, and strip or lock behind a build-time flag anything that can redirect network endpoints or expand permissions.

ExpectedAs reported, Meta's fix — stripping the debug preference from production builds — closes the exact path an attacker used to intercept credentials and audio and inject hidden instructions through the trusted agent.
