How Datadog built a "universal machine tool" for Claude Code

claude_blogJul 21Details

Datadog has an agent write specifications that feed a deterministic kernel, which then generates the application code — trading direct LLM code generation for a spec-first, reproducible pipeline.

Playbook takeaway

ProblemAgent-generated application code is hard to trust in production because there's no single artifact that's both the proof of correctness and the thing that actually runs.

ApplyHave the agent emit a formal specification — behavior as a state machine, data as machine-readable entity definitions, authorization as default-deny policy — and let a deterministic kernel verify it via symbolic reasoning, exhaustive state exploration, fault-injected simulation, and property testing before it becomes the running system.

ExpectedDatadog's Temper kernel makes agent output repeatable and inspectable because the verified specification is the deployed system, eliminating drift between what was proven safe and what ships.

Securing the AI-Native SDLC 3 items

As AI writes more of the code that ships, three items today addressed the same question from different angles: how do you secure a development process where the author is no longer only human.

How Anthropic secures its AI-native software development lifecycle

claude_blogJul 21Details

Anthropic's Deputy CISO, Jason Clinton, details how the Security Engineering team secures an SDLC where AI now authors 80% of merged code.

Playbook takeaway

ProblemManual security review can't scale once AI is authoring the majority of merged code — bugs need catching before they're generated, not after a human skims a diff.

ApplyEncode your org's security guidelines directly in CLAUDE.md and skills so generated code follows them from the first draft, run /security-review to flag attacker-controllable input during development, and stack multiple narrow-scope review agents (each with RAG context, none with full-repo authority) ahead of a human reviewer who samples risk-weighted approvals.

ExpectedAnthropic estimates about a third of past claude.ai incidents would now be caught automatically, and PR comment engagement rose from 16% to 54% as teams trusted the automated findings.
