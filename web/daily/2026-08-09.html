Stripe Uses Graph Search and State Machines to Automate Database Remediation

infoq_ai_mlDetails

Stripe's engineering team modeled its global infrastructure as a graph and combined graph-search algorithms with state machines to automate database incident recovery.

Playbook takeaway

ProblemHard-coded remediation runbooks for sharded database incidents break as infrastructure topology changes, and complete-or-nothing fixes leave engineers paging in even when a partial fix is possible.

ApplyModel your infrastructure as a graph — nodes for components, edges for relationships, attributes for health state — and run Dijkstra's algorithm over it to find the lowest-cost valid recovery path, including partial remediations when no complete fix path exists, instead of maintaining static scripts per failure mode.

ExpectedStripe cut database-related pager alerts 30% (200 fewer pages a year) and eliminated 12 days a year of unhealthy shard states by moving from scripted runbooks to graph-search remediation.
