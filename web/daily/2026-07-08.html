Tuning the harness, not the model: a Nemotron 3 Ultra playbook

langchain_blogDetails

LangChain tuned Nemotron 3 Ultra's harness, not the model itself, to match Opus 4.8's best agent run at roughly 8x lower cost.

Playbook takeaway

ProblemRunning a frontier model on every agent step gets top-tier quality, but at $43.48 per full eval-suite run in LangChain's benchmark — a per-run cost that doesn't scale to high-volume usage.

ApplyBefore swapping in a bigger model, tune the harness around a cheaper open model: add short, single-purpose system-prompt blocks that target one observed failure (e.g., requiring concrete results instead of vague completion claims), enforce call caps and one-shot retry logic in middleware to stop looping, and move instructions into a tool's returned output rather than its description so guidance sits next to the data the model is reading.

ExpectedLangChain closed Nemotron 3 Ultra from a 0.80 to a 0.86 score against Opus 4.8's 0.87 best run, at roughly $4.48 per full suite — about 10x cheaper — with latency at parity.
