SkillSpec – verify that agent skills run the way SKILL.md says

hackernews_aiDetails

A tool to verify that an agent skill actually behaves the way its SKILL.md contract claims — testing the spec, not just the prose.

Playbook takeaway

ProblemA skill written as prose in SKILL.md can be skipped, reordered, or substituted by the model at runtime — there's no way to prove a run actually followed the documented steps, which matters once you're managing many skills at scale.

ApplyRun a doctor-style check against each skill to surface buried instructions and unprovable steps, then convert the must-follow parts — route selection, phase ordering, allowed/forbidden tools, required validations — into a separate machine-checkable contract file the agent consults at runtime, following SkillSpec's `skill.spec.yml` pattern. Keep genuine judgment calls in prose; move only the hard constraints into the contract.

ExpectedSplitting judgment from must-follow rules turns a followed-or-not guess into a run you can actually audit, instead of hoping the model executed the SKILL.md instructions in order.
