Presentation: The Agent Harness: Control Planes, Invariants, and Approval Boundaries for Production AI Agents

infoq_ai_mlDetails

OpenAI's Vinoth Govindarajan argues production agents fail beyond hallucination, and lays out control planes, invariants, and approval boundaries as the fix, using the OpenClaw incident as a case study.

Playbook takeaway

ProblemProduction agents fail from harness gaps, not just hallucination: a fact with no durable owner, concurrent writes with no order, a tool call with no timeout, or an action with no receipt each look fine until they aren't.

ApplyBefore shipping, name one owner and replay path for every fact the agent depends on, serialize same-process writes through a queue (and cross-process writes through a lock), give every tool call and stream an explicit deadline and terminal state, scope every approval to actor/session/tools/arguments/lifetime, and require a receipt — not just a transcript — before treating an action as done.

ExpectedOpenAI's presenter claims this closes failure modes that hallucination-focused evals miss: the model proposes, the harness commits, and the receipts prove it.
