Agent Evaluation Metric for multi-turn conversations

aws_ml_blogDetails

AWS introduced the Agent Evaluation Metric, a decomposable, turn-level score for multi-turn agents that addresses how one early mistake can silently corrupt every later turn under whole-conversation evaluation.

Playbook takeaway

ProblemTask-level multi-turn eval counts every downstream turn that inherits an earlier mistake as its own failure, so one bad tool call in turn 2 reads as four failures instead of one root cause.

ApplyDecompose each turn's correctness into truthfulness and completeness sub-scores using semantic match instead of exact string match, and tag each failing turn as an independent error or `prior_action_failed` when it only inherited an upstream mistake.

ExpectedAWS's five-turn sales-report example collapses from 4 reported failures to 1 root cause plus 3 correctly-attributed cascades, pointing fixes at the actual defect instead of every symptom.
