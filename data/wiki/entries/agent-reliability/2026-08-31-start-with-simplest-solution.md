Anthropic's "Building Effective AI Agents" sets the default explicitly: start with the **simplest solution that works**, often a single well-prompted call, and move to a workflow or an autonomous agent only when the added complexity demonstrably improves outcomes.

Agentic autonomy is a cost to justify, not a default architecture.
