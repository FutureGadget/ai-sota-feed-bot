Phil Schmid notes that agents can already edit their own tools, skills, and harness. Recursive self-improvement still needs a system that can **raise the verifier without the agent capturing it**.

A self-modifying agent can also modify its own check. Any self-improvement loop needs a verifier the agent cannot rewrite.
