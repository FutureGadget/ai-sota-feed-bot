Multi-agent routers decide which agent gets a task from **unverified proxies**: an agent's textual self-description or a static surrogate representation. The Linguistic Firewall paper treats the gap between an agent's projected profile and its actual competence as a security problem and proposes a geometry-based defense for routing.

The routing layer is an attack surface: an agent that misdescribes itself can capture work it should not get. Robust handoffs are a security property, not just a quality one.
