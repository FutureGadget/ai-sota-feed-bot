Jefferies built a front-office trading assistant on **Strands Agents**, an open agent-harness SDK, with Amazon Bedrock and Bedrock Knowledge Bases, plus MCP for unified access to trading data sources and tools.

A regulated bank chose an open harness on a managed model platform rather than a single-vendor agent product. The write-up is an AWS blog post, so read it as a reference architecture, not an independent evaluation.
