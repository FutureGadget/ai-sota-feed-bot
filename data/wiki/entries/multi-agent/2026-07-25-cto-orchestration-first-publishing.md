A CTO's long-form publishing project, built orchestration-first instead of one model handling the whole workflow, grew to **25 agents and tools, 30 agent skills, 12 MCP/A2A-native services, and 318 PRs**, processing **26 billion tokens**. It was run solo, deliberately, before asking the wider engineering organization to work this way.

Proving the pattern on one builder's project first surfaces the plumbing cost before a team commits to it.
