LinkedIn's **Cognitive Memory Agent (CMA)** is an infrastructure layer that gives agents persistent memory across episodic, semantic, and procedural layers, with support for multi-agent coordination, retrieval, and lifecycle management.

It is a useful reference architecture for the tiered split: working context, a log of past interactions, and durable facts and procedures. It also treats memory as shared platform infrastructure for many agents, not a per-agent prompt feature.
