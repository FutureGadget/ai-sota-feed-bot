---
title: "An open Add/Search evaluation framework makes agent memory systems comparable"
date: 2026-09-18
theme: measuring-memory
evidence: [934ca800d677c018]
---
An open evaluation framework defines agent memory by two fixed primitives, **Add** (write) and **Search** (retrieve), so different systems can be compared **without each team choosing its own answer model and evaluation pipeline**.

It extends the Agent Memory Leaderboard's approach into reusable tooling. Fixing the boundary between memory system and evaluator is what makes vendor numbers comparable.
