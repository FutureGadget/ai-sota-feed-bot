The **Agent Memory Leaderboard** released first results for text memory in two tracks, open-source methods and commercial products. 136 teams registered and 69 frameworks completed the run. Commercial leaders: MemoraX 58.02, MemOS 45.89, NTES-MEMORY-SMART 44.21.

Every entrant runs through one pipeline: memory system **Add → Search**, then benchmark **Answer → Eval**. A system can't win by picking its own answer model or evaluation setup, as vendor demos can.
