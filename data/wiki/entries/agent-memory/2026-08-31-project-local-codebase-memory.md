Two more developer-owned stores shipped within days of each other:

- **Contextual**: local codebase memory for AI coding agents
- **OpenContext**: persistent, project-local memory served over [MCP](/topic/mcp)

Both keep memory inside the project rather than in a hosted service. The local-first roster is crowded enough that differentiation now comes from write discipline and recall quality, not from storing memory locally.
