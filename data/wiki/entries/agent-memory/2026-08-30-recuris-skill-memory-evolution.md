**Recuris** pairs a working memory that tracks task progress and guides skill selection with an experiential memory of reusable skills. After each failure, a meta-agent makes localized, validation-gated edits to the skill store.

It improves **35 of 37 model-benchmark pairs**, gains reach +32.2 points on the longest-horizon tasks, and long-horizon failures drop by up to 80%. Skill memory pays off precisely where compaction and retrieval get harder.
