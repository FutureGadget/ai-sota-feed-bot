A new open benchmark scores **the failure modes of agent memory**: forgetting, stale recall, poisoning, and retrieval that returns the wrong slice.

It turns "did the memory layer help" into a number you can regress on, the trajectory evaluation already took with [agent benchmarks](/topic/agent-benchmarks).
