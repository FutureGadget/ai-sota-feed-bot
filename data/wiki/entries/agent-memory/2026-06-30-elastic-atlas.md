Elastic's **Atlas** maintains three categories of agent memory on top of Elasticsearch, integrates with agents over [MCP](/topic/mcp), and keeps each user's memories isolated. On question answering it scored **0.89 Recall@10**.

It is an open, production-grade instance of the tiered model, built on infrastructure many teams already run, and it ships evaluation numbers rather than a demo.
