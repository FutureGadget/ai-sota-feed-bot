Three more grassroots launches landed within a week:

- **Captain Memo**: one local package of memory, skills, and capabilities any coding agent can use
- an **open-source shared memory for teams** of AI coding agents
- **Memanto.ai**, another agent memory service

They target the same cross-agent, cross-session recall gap as Sibyl and Awareness Local. Captain Memo's twist is packaging skills alongside memory.
