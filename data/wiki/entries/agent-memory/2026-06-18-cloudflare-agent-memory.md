Cloudflare's **Agent Memory**, in private beta, extracts structured memories from agent conversations and retrieves them on demand with **five-channel parallel retrieval fused by Reciprocal Rank Fusion**. Shared memory profiles let teams of agents read common knowledge. It competes with Mem0, Zep, LangMem, and Letta.

This is the buy side of the build-vs-buy split: memory as rented infrastructure next to your edge compute.
