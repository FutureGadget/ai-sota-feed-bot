**OpenWiki Brains** turns sources such as Gmail, Notion, git repos, X, Hacker News, and web search into a local wiki of plain Markdown files that agents read as fresh memory.

The memory layer is synthesized Markdown refreshed by scheduled jobs, not a vector index. Recall is proactive: the agent draws on it without being told to remember, unlike the reactive "remember this" pattern most assistants ship.
