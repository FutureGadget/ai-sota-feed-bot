**DolphinBench** evaluates memory through an agent's **task completion** on real-world, action-dependent recall, not conversational QA where the question itself signals which fact to fetch. It also maps the **Pareto frontier of accuracy against cost and latency** instead of naming one winner.

Benchmarks that reward accuracy alone let memory systems make unreasonable cost trade-offs. Read memory leaderboards with the cost axis attached.
