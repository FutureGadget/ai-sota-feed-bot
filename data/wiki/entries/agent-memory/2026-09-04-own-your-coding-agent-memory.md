Hugging Face's "Give Your Coding Agents a Memory You Own" (the Funes project) makes the **"own your memory, don't rent it"** pitch explicit.

A major platform endorsing developer-owned memory strengthens the local-first side of the build-vs-buy split against managed services like Cloudflare's Agent Memory.
