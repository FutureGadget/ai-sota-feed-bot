LinkedIn's **Contextual Agent Playbooks and Tools**, built on [MCP](/topic/mcp), serve procedural memory, code search, and runbooks directly to coding agents to work around their limits in large codebases. LinkedIn reports a **20% productivity boost with zero loss in reliability** (self-reported).

The tiered model built as a codebase-scoped organizational context layer, with operational guardrails, rather than a reference diagram.
