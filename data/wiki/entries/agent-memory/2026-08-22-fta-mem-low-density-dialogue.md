**FTA-Mem** targets emotional-support agents, where dialogue is low-density: turns are incomplete, evidence is scattered, and user state shifts over time. Fixed units such as turn notes or session summaries either lose detail or add noise.

It segments conversations into coherent situation fragments and anchors memory to **fact, time, and affect**. For sparse, long relationships, the memory unit itself has to be designed, not just the store.
