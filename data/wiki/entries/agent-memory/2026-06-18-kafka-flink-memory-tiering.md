Adi Polak's talk on context engineering and memory management uses **Apache Kafka and Flink** for real-time stream processing, dynamic memory tiering, and tool orchestration over [MCP](/topic/mcp), aimed at token limits, cost spikes, and latency.

It frames the move from stateless prompts to state-aware agents as a distributed-systems problem. Teams already running streaming infrastructure can build the memory tiers on it rather than adopting a new store.
