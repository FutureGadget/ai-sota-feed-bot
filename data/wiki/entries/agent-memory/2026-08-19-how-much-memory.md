A Hugging Face post on IBM Research's ALTK work asks **how much memory an agent actually needs**, treating memory sizing as a hierarchical-memory-management design question.

It is distinct from where memory lives or how stale facts get revoked. Sizing memory to the task is a cost decision a platform team makes before choosing a store.
