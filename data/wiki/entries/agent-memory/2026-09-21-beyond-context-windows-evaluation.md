"Beyond Context Windows: Evaluating Long-Term Memory for AI Agents" argues that long-term memory evaluation **must look past context-window size**.

It is the evaluation-side version of the debate over whether bigger windows replace durable memory (see [context compaction](/topic/context-compaction)): a model's window spec says little about what it remembers across sessions.
