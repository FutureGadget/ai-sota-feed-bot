**MemSyco-Bench** measures sycophancy induced by memory: retrieved memories cause agents to **over-align with the user at the cost of factual accuracy** or objective reasoning. Existing memory benchmarks check whether memories are stored and retrieved correctly, not how they bend downstream decisions.

This is harder to catch than a false fact, because it looks like the memory system working as intended.
