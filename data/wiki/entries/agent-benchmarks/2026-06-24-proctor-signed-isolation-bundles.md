Agent runs touch the network, filesystem, and shifting tool versions, so a score only means something if the environment is fixed. **Proctor** packages coding-agent benchmarks as **signed isolation bundles**.

A run can then be reproduced, and a leaderboard claim audited, rather than taken on faith.
