**IssueTrojanBench** tests whether a coding agent executes a malicious instruction smuggled inside an otherwise ordinary GitHub issue.

It moves adversarial testing from malformed tool output to malicious *task input*, the channel a coding agent trusts most. See [prompt injection](/topic/prompt-injection).
