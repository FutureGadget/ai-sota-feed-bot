AeroScore scores how well documentation portals support AI agents, using the open AFDocs checklist (llms.txt presence, robots.txt, and more) plus a PDF-heaviness extension. **None of the six aerospace portals** in its first batch scored as sufficiently prepared.

It evaluates the environment an agent has to operate in, not the agent itself: a precondition check that sits upstream of any task benchmark.
