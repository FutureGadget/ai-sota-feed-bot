Stripe's 11-environment benchmark scores agents on **real Stripe integrations**: checkout migration, billing API work, and full-stack browser checkout. The best runs needed roughly 63 interaction turns.

The two leading models (92% vs 73%) **failed the identical validation step** rather than differing on raw coding ability. Validation, not code generation, is where integration agents break.
