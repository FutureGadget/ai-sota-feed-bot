An open agent-security benchmark scores defenses against a fixed attack suite and **publishes the attacks it fails to catch**, not only the ones it blocks.

Reporting your own detection gaps is the honest default for a security eval. See [prompt injection](/topic/prompt-injection) for the attack side.
