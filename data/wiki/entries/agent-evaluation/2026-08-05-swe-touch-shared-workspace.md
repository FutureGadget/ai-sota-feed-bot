Repository-level benchmarks usually evaluate agents working alone, or limit user participation to messages. **SWE-Touch** tests how coding agents understand and respond when users **inspect and modify code in the shared workspace during a task**.

That is the normal case for an IDE agent, so uninterrupted-run scores leave a gap.
