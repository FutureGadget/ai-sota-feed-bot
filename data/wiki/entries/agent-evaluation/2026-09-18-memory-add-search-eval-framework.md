The Agent Memory Leaderboard team released an **open Add/Search evaluation framework** that stops each memory vendor from choosing its own answer model and evaluation pipeline, alongside a write-up on evaluating long-term memory beyond context windows.

Standardizing the pipeline closes off a team picking a favorable judge to inflate its ranking. Memory evaluation also has to ask whether stored memory is still **current**, not just once correct; see [agent memory](/topic/agent-memory).
