Supabase released **Supabase Evals**, an open-source benchmark that scores how well coding agents — Claude Code, Codex, and OpenCode — build on Supabase using real tasks.

It joins AWS-bench as a platform vendor publishing its own agent benchmark. For teams on that platform it is a closer proxy than a general SWE score; check the task set before treating it as neutral.
