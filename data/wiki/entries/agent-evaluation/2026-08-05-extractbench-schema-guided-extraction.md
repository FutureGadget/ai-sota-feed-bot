**ExtractBench** benchmarks schema-guided enterprise document extraction: given a document and a user-defined schema, the agent must produce correct output with **source evidence as grounding metadata**. It scores value accuracy and record completeness at scale, among other measures.

For extraction pipelines, attribution is part of correctness, not a nice-to-have.
