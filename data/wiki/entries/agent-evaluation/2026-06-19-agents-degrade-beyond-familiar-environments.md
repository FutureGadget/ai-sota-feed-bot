"Running the Gauntlet" argues current agent benchmarks are built on popular applications with relatively simple tasks and a narrow set of capabilities, so modern agents **saturate** them. Re-evaluated beyond familiar environments, agent capability drops.

Static leaderboards over-state real-world capability. Test on your own environment and tools before trusting a headline score.
