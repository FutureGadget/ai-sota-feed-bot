Grab's **LLM-Kit** standardizes secret handling, runtime tool discovery, model integration, and **evaluation integration** across more than **500 internal agent services**, cutting time to deploy a new agent from about two weeks to about one hour.

A paved-road framework that includes eval from the start beats leaving each team to assemble it. See [agent sandboxing](/topic/agent-sandboxing) for Grab's security-side platform.
