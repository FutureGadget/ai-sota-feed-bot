Google's **AlphaEvolve** reached general availability on the Gemini Enterprise Agent Platform as an evolutionary code-optimization service. Evaluators run **client-side**, so code never leaves the customer's infrastructure; Klarna reports **doubling ML training throughput**.

Practitioners note it only works where a measurable evaluation function exists. Teams with a scorable objective can hand optimization to an agent; teams without one hit the fuzzy-spec wall first.
