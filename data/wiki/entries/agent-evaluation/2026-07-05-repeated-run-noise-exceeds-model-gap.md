A practitioner analysis in Dan Luu's notes measured **one standard deviation of 7.5%** between repeated runs of the same model on a coding task — larger than the gap between the best- and worst-ranked models in the comparison. Dropping or swapping a handful of tasks from a ~100-task set was enough to change which model won.

Single-run leaderboard gaps of a few points are not evidence of a better model. Report variance across repeated runs and task subsets.
