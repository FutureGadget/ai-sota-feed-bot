**Favur**, a Python multi-agent harness of 14 role-specialized agents coordinated by code rather than an LLM orchestrator, scores runs across models on the same standardized statement of work. The composite score covers eight subjects — code quality, test quality, cost efficiency, velocity, tool discipline, effort efficiency, process discipline, deliverables — computed from each run's artifacts.

Every scored run can be **replayed end-to-end**, which makes the published score checkable rather than taken on trust.
