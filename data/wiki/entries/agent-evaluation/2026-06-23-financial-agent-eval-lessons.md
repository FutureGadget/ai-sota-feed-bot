A practitioner write-up, "Lessons from Building Evals for Financial AI Agents", reports what building evals for financial agents taught over several years.

Its central warning matches other field reports: an eval suite can pass while the agent fails in the way that matters, because the suite never encoded the real-world failure. Start from observed failures, not a generic checklist.
