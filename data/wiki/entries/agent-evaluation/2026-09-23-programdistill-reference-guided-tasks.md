**ProgramDistill** evaluates coding agents on features discovered by **interacting with fully functional reference web apps**, then implemented in an incomplete application — instead of behavior specified in an issue or instruction.

It measures whether an agent can infer intended behavior from working software, a common real task that issue-driven SWE benchmarks skip.
