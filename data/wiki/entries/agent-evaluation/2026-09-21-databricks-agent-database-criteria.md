Databricks lists five criteria for evaluating a **database for AI agents**, naming **branch isolation** and a **serverless** architecture among them.

Evaluation targets now include the infrastructure agents run on, not only the agents. Branch isolation matters most where agents write data and need a safe place to try changes.
