Cassie Shum's InfoQ talk lays out four patterns for building agents on a knowledge graph instead of basic RAG: **context bundling, decision provenance, code as truth, and agent visibility**. She demonstrates an engineering harness on a graph that shortens feedback loops and reduces token use.

Decision provenance puts attribution into the retrieval architecture itself rather than bolting it on as a separate scoring step.
