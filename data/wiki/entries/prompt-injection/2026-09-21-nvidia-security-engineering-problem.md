NVIDIA argues AI security is an **engineering problem**: defined security requirements, enforceable controls, named owners, and evidence that protections work, applied at every layer of the agent stack.

It restates the case for authorization over prompt hygiene as an accountability requirement. For a platform team, that means each agent control has an owner and a test that shows it working.
