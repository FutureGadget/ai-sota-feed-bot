Deep-XPIA is an open benchmark for **indirect prompt injection across agents** in multi-agent systems, where one compromised agent's output becomes another agent's trusted input.

Single-agent injection tests miss this path. If your agents hand work to each other, measure what a poisoned upstream output can make a downstream agent do. See [multi-agent](/topic/multi-agent).
