A security researcher encoded pre-AI audit techniques into a fully autonomous Codex campaign against Webmin 2.670, about 386,000 production lines of Perl/CGI. It produced **507 canonical, reproduced findings** with CVSS 4.0 assessments over 524 exploit paths. The run used 8.35 billion model tokens, which the author prices at **about $4,578** at current standard API rates.

For builders and defenders: an autonomous audit of a large legacy codebase now costs a few thousand dollars in tokens. Attackers get the same price, so audit exposed legacy admin surfaces this way before they do.
