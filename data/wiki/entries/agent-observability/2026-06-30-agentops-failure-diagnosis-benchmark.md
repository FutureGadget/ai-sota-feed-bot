A new benchmark for **AgentOps** evaluates LLM agents on microservice failure diagnosis over multimodal observability data. It adds two large datasets because existing benchmarks score only the final answer and ignore the reasoning process.

Grading whether an agent diagnosed a failure correctly is a trajectory-grading problem, so agent observability and [evaluation](/topic/agent-evaluation) converge on the trace.
