LangSmith now positions itself as the **debug console for any coding agent**: Claude Code, Codex, Cursor, Copilot, and more. One view shows tool calls, subagent handoffs, errors, cost, and retries.

Which agent produced a trace becomes a detail the observability layer abstracts away, instead of a reason to read each tool's own logs.
