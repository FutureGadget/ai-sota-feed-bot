Anthropic published a guide that walks IT admins through Claude's cost surface end to end: **spend caps, model controls, usage analytics**, and cost-relevant API features such as prompt caching and batch processing.

The value is consolidation. Settings that were scattered across a console become one playbook, and it puts caching and batch next to caps, so a team sees both the levers that bound spend and the ones that lower it.
