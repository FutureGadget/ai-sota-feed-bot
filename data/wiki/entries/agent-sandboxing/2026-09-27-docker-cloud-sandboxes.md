**Docker Cloud Sandboxes** are hosted execution environments for AI coding agents on Docker-managed infrastructure, built on **hardware-enforced microVM isolation**, with a unified CLI for moving the same workload between a developer's laptop and the cloud.

The pitch is environment consistency rather than a new isolation primitive: the sandbox a developer tests locally is the one that runs in production.
