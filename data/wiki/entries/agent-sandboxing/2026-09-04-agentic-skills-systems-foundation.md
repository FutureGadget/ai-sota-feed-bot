"Towards a Systems Foundation for Agentic Skills" formalizes **skills** as modular, reusable, executable, portable procedural artifacts that move execution logic out of monolithic prompts and stateless tool calls. It proposes a unified reference architecture covering skill **architecture, lifecycle, and security**.

Skills are code an agent loads and runs. Treat their provenance, review, and execution context like any other dependency inside the sandbox.
