title: "VPC Service Controls adds agent guardrails: a network perimeter around the data an agent can reach"
date: 2026-06-27
theme: egress-and-escapes
evidence: [655ca293c796f3fd]

Google Cloud added agentic-AI capabilities to **VPC Service Controls**, a network-level, destination-based perimeter around the data and services an agent can touch.

A hijacked agent holding valid tokens still cannot move protected data outside the perimeter. Identity limits what the agent may do; the perimeter limits where data can go even when an action is authorized.
