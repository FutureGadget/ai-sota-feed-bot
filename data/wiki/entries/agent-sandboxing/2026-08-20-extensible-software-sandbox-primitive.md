Jeremy Morrell argues that LLMs radically lower the cost of authoring extensions and **modern sandbox primitives lower deployment cost and supply the security boundary**. Ship a solid, accountable core and let users extend it with LLM-filled pieces.

Read from inside one team, sandbox controls look like friction. Read as a product primitive, the same boundary is what makes running someone else's generated code shippable at all.
