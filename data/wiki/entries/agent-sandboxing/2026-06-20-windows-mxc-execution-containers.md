Microsoft's "Windows platform security for AI agents" post introduces the **Microsoft Execution Containers (MXC) SDK** and argues that containment, identity, and manageability must be built into the operating system.

The sandbox boundary moves down into the OS on the desktop, instead of each agent vendor shipping its own process wrapper.
