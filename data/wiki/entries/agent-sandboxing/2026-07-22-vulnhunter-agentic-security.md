Capital One published **VulnHunter**, an open-source agentic AI security tool aimed at automated vulnerability discovery and patching.

Together with managed offerings such as CodeMender, automated find-and-fix joins static analysis as a control on agent-written code, one that acts on a finding instead of only flagging it.
