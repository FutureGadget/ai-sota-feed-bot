Simon Willison collects anecdotes of people using coding agents to **reverse-engineer undocumented home-device APIs** and automate them. Before agents this was possible but rarely worth the maintenance risk. When writing the automation is nearly free, so is throwing it away and rewriting it when the API changes.

The ROI shift is not only a lower per-task bill. It removes the cost that used to gate the work, so the set of things worth building grows.
