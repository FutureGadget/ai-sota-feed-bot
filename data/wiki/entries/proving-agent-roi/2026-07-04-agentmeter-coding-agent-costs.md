AgentMeter, an open-source tool, tells a developer **what their AI coding agents cost**, breaking token spend down by agent rather than leaving it in one provider bill.

Session-level attribution is the raw material for an ROI case. Without it, the only number available is aggregate API spend, which cannot be set against any single outcome.
