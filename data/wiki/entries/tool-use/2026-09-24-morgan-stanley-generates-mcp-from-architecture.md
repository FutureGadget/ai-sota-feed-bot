Morgan Stanley models its API program with Architecture as Code (the **CALM** framework) and generates Model Context Protocol and Agent-to-Agent (A2A) integration surfaces from that description, with governance enforced through deployment gates.

Agent-callable tooling becomes a byproduct of API governance already in place, not a separate integration project with its own servers to hand-write.
