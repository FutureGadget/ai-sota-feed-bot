Uber's shared marketplace of agent skills (Markdown `SKILL.md` workflows with optional scripts) grew from **1** skill in October 2025 to more than **5,000** a year later, with over **1 million** invocations in one month. Agents load skills in three stages, so thousands cost only a short description each until one is used. At that scale Uber tiers skills by quality and evaluates invocations, using agents to help maintain them.

For builders: once anyone can publish a skill, the catalog becomes a quality problem like a package registry. Plan for ownership, tiering, and invocation-level evaluation before skills multiply.
