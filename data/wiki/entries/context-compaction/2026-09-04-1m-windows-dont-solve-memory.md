A practitioner post argues that **1M-token context windows won't solve agent memory** and proposes a continuity protocol instead.

The argument: a longer window is still discarded between sessions and still degrades under context rot within one long run. A bigger window is orthogonal to durable memory, not a substitute for it. This is the counterweight to the "just extend the window" results.
