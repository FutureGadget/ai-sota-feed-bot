LangSmith now positions itself as one debug console for coding agents from different vendors: **Claude Code, Codex, Cursor, and Copilot**. It shows tool calls, sub-agent handoffs, errors, cost, and retries in one place.

For teams whose engineers use several coding agents, the trace format matters more than which agent produced the trace.
