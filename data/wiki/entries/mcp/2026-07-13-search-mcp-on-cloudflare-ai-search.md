A Show HN **search MCP** uses Cloudflare AI Search to index repositories and other material, so an agent can retrieve project-specific reference information instead of relying on what is already in its context. It is AGPL-3.0 and includes a web widget for end users.

Retrieval over a team's own material becomes one more MCP server rather than a custom RAG integration per agent.
