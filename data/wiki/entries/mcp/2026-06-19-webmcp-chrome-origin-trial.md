Google put **WebMCP** into origin trials in Chrome 149. Sites can expose tools, such as JavaScript functions and HTML forms, to in-browser agents.

Agents can act through declared tools instead of costly screen reading or unreliable DOM scraping. The actuation surface for MCP extends to the web page itself.
