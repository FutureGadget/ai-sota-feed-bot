Dropbox integrated MCP with **Dash**, its internal knowledge platform, so AI-assisted code review retrieves the **threat model and security requirements** for a pull request and checks the implementation against design intent.

Security design context rides the same protocol as a tool call, reaching the review step where it is usually missing.
