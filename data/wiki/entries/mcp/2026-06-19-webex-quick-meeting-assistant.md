An AWS reference build wires **Amazon Quick and Cisco Webex MCP servers** into one assistant. From a single prompt it finds an upcoming Webex meeting, reviews prior summaries, transcripts, and Vidcast highlights, searches message threads for unresolved follow-ups, and writes a prep brief.

Vendor SaaS servers compose into a working workflow without custom integration code.
