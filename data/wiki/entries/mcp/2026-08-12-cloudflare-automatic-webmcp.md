Cloudflare previewed **automatic WebMCP support**: any site can enable a WebMCP interface from a single dashboard switch, with no code change. Browser-based agents then interact with the unmodified page through structured tools instead of scraping, while human traffic stays on the original site.

WebMCP moves from an origin trial a team opts into to a toggle a site operator flips.
