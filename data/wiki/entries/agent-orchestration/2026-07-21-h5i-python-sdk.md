h5i-python, the SDK for the h5i orchestra engine, defines and executes **multi-agent coding workflows across Claude Code, Codex, and other runtimes as ordinary Python programs**.

It is Omegacode's thesis in a second language: coordination is portable code, not a per-provider integration.
