OpenAI's **Agents API** is a managed service, **powered by the Codex harness**, for building and launching cloud agents, with orchestration, long-running sessions, and tool use handled by the platform.

The lab that trains the model now also sells the harness as a runtime, joining Microsoft and LangChain. It is one more managed option to weigh against the portability argument AWS makes.
