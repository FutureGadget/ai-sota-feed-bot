Intent, a coding-agent orchestrator built to run **hundreds of agents in parallel** across isolated workspaces, went open source. A Coordinator agent turns a stated intention into a spec, specialist agents execute against it while sharing context, and git integration handles commits and review.

It targets the high-agent-count end of the problem, where the spec and workspace isolation carry the coordination rather than a small fixed topology.
