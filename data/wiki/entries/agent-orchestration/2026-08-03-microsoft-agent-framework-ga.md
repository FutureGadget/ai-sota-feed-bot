Microsoft's Agent Framework (the Agent Harness, **GitHub Copilot and Claude Agent SDK connectors**, and orchestration patterns, all stable since Build 2026) now ships the harness and **Foundry Hosted Agents at general availability**.

The shift is from an SDK you assemble to a governed, supported runtime for running agents.
