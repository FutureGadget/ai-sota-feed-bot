An Ask HN thread asks for multi-LLM frameworks where models genuinely collaborate. The poster's split: **Gemini for high-level refactoring and architecture, GPT/Claude for implementation**, a handoff they report already doing by hand.

The request is a routing-and-handoff problem, not a model problem. The tools that followed on this page (Kimchi, Omegacode, GitHub's HydraFusion) are answers to it.
