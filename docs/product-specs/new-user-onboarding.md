# New User Onboarding

## Goal
Get a new user receiving useful digest output in <15 minutes.

## Steps
1. Fork/clone repo
2. Configure source/profile yaml
3. Set GitHub Action secrets
4. Trigger the `feed-full-publish` workflow (or run `skills/ai-feed-digest-local/scripts/run_full.sh` locally)
5. Validate website, RSS, and email delivery
